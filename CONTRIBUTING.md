# Contribuir / Contributing

## Español

Las contribuciones al código y documentación propios se reciben bajo MIT; conserva avisos y declara procedencia/licencias de cualquier activo o dependencia añadidos. No se exige CLA ni cesión de derechos. Usa Node.js 24 LTS y Python 3.10+, ejecuta `npm ci --ignore-scripts` y `npm run verify`. Edita extension y scripts, no dist. Explica problema, solución, pruebas y navegador/versión.

Mantén destacados efímeros, sin almacenamiento, red ni actividad continua. Justifica dependencias. No adjuntes datos privados, perfiles ni credenciales a informes. Comprueba recarga, pestañas, navegación atrás, editores y restricciones. No presentes mocks como pruebas de navegador. Repositorio y canales de GitHub disponibles; consulta SUPPORT.md y SECURITY.md.

## English

Contributions to original code and documentation use MIT; preserve notices and declare provenance/licenses for added assets or dependencies. No CLA or copyright assignment is required. Use Node.js 24 LTS and Python 3.10+, run `npm ci --ignore-scripts` and `npm run verify`. Edit extension and scripts, not dist. Explain the problem, solution, tests and browser/version.

Keep highlights ephemeral, without storage, networking or continuous activity. Justify dependencies. Never attach private data, profiles or credentials to reports. Check reloads, tabs, back navigation, editors and restrictions. Do not present mocks as browser tests. Repository and GitHub channels are available; see SUPPORT.md and SECURITY.md.
