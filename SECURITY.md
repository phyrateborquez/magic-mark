## English

### Private channel

Report vulnerabilities at https://github.com/phyrateborquez/magic-mark/security/advisories/new. GitHub Private Vulnerability Reporting is enabled, verified through the GitHub API on November 13, 2026. Maintainer: phyrateborquez. No public security email or guaranteed response times. Do not post vulnerability details in Issues.

### Private report contents

Magic Mark version, browser/version, impact, minimal steps and invented example content. Do not attach profiles, cookies, credentials, history or private selections. Coordinate disclosure with the maintainer; confidentiality of public channels and remediation deadlines are not promised.

### Scope and dependencies

The tested desktop MVP 0.1.3 scope is recorded in ROADMAP.md. There is no old-version maintenance policy yet. The installed extension contains no runtime dependencies.

Historical review on November 12, 2026: npm audit reported three low-severity entries along deepmerge 4.3.1 → addons-linter → web-ext 10.8.0, development-only. No compatible fix was published at that check; the validator was not forcibly downgraded. Recheck before submission. This is not an exhaustive security audit or a claim that the advisory was fixed.
