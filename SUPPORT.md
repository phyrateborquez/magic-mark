# Magic Mark · Soporte / Support

## Español

### Canal de soporte

Errores y mejoras: https://github.com/phyrateborquez/magic-mark/issues. Mantenedor: phyrateborquez. README contiene instrucciones de uso. No se publica correo personal ni hay tiempos de respuesta garantizados; el mantenimiento es voluntario.

### Antes de informar

Comprueba que seleccionaste texto HTML fuera de formularios y editores. PDF integrado, imágenes y páginas protegidas no están cubiertos. Prueba el botón o el menú si tu atajo está ocupado. Recargar o cerrar elimina las marcas por diseño; no hay recuperación. Un sitio que reemplaza texto puede perder sus marcas. Si falla una acción, consulta el mensaje del icono al pasar el puntero.

### Informe útil

Incluye versión de Magic Mark, navegador y versión, sistema operativo, pasos mínimos y resultados esperado y observado. Usa texto inventado y capturas sin datos personales. No envíes perfiles, cookies, contraseñas, historial ni selecciones privadas. No se recopilan diagnósticos automáticamente.

Las vulnerabilidades se comunicarán por el canal privado descrito en SECURITY.md, ya habilitado. No abras incidencias públicas con detalles sensibles.

## English

### Support channel

Bugs and suggestions: https://github.com/phyrateborquez/magic-mark/issues. Maintainer: phyrateborquez. Usage instructions are in README. No personal email is published and no response time is guaranteed; maintenance is voluntary.

### Before reporting

Check that you selected HTML text outside forms and editors. Built-in PDFs, images and protected pages are excluded. Try the button or menu if your shortcut conflicts. Reloading or closing removes highlights by design; there is no recovery. Sites replacing text may lose highlights. If an action fails, hover over the icon to read its message.

### A useful report

Include Magic Mark version, browser and version, operating system, minimal steps, expected and actual results. Use invented text and screenshots without personal information. Do not send profiles, cookies, passwords, history or private selections. No diagnostics are collected automatically.

Report vulnerabilities through the private channel described in SECURITY.md now enabled. Do not open public issues containing sensitive details.
